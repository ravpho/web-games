# web-games
Simple games for kids

| Game | Folder | What it is |
|---|---|---|
| Straw Hat Showdown | [`straw-hat-showdown/`](straw-hat-showdown/) | One-on-one fighting game for phones with Luffy, Zoro, Sanji and Nami (unofficial *One Piece* fan game) |

## How to play Straw Hat Showdown

Open the game on a phone and hold it sideways. Tap the title, pick your fighter, pick an opponent, and choose Easy, Normal or Hard.

- **Left thumb**: touch anywhere on the left side and drag to walk; drag up to jump (up-left or up-right to jump that way).
- **Attack**: tap up to three times in a row for a combo.
- **Special**: a special move. Hold toward your opponent while pressing it for your other special.
- **Guard**: hold to block. Special moves still chip off a little health.
- **Super**: lights up when your meter is full (it fills as you hit and get hit). Press it for your big move.

Win two rounds to win the match. Each round lasts 60 seconds; if time runs out, whoever has more health wins.

On iPhone, use Share > "Add to Home Screen" to play fullscreen. After the first visit the game also works offline.

## Run locally

The games are plain HTML, CSS and JavaScript with no build step and no dependencies. Serve the repo root with any static file server, for example:

```sh
npm start            # same as: npx serve -l 8080 .
```

Then open <http://localhost:8080/> and pick a game. To try the touch controls in a desktop browser, turn on device emulation (a phone, held sideways) in the developer tools.

Offline support is switched off on `localhost` so you always get fresh files. Add `?sw` to the address to test it locally.

## Tests

The fight logic, computer opponent and sound mapping have unit tests that run in Node 22 with no dependencies:

```sh
npm test             # same as: node --test
```

## Build and publish

```sh
node tools/build-site.mjs     # writes the publishable site to _site/
```

This copies the games index and each game without its `tests/` folder. It also stamps the game's service worker with a version and the list of files to save for offline play.

The [workflow](.github/workflows/pages.yml) runs the tests on every push. On `main` it also builds the site and publishes it to GitHub Pages.

**One-time setup:** in the repository on GitHub, open **Settings > Pages** and set **Source** to **GitHub Actions**. GitHub Pages on a private repository needs a paid GitHub plan, so on a free account the repository must be public. The game is then at `https://<owner>.github.io/web-games/straw-hat-showdown/`.

The app icons in `straw-hat-showdown/icons/` are drawn by the game's own code. To redraw them after changing the hat, run `node tools/make-icons.mjs` (needs Playwright with Chromium).
